This project is a modular travel planning assistant powered by CrewAI, using autonomous agents to handle travel recommendations, bookings, and itinerary generation.

✨ Features

✅ Travel Recommendations – Suggests destinations based on user preferences

✅ Booking Support – Assists with flight and hotel bookings

✅ Itinerary Planning – Creates detailed travel plans and schedules

✅ Autonomous Agents – Tasks are delegated to specialized agents for efficiency

✅ Web Search Integration – Uses DuckDuckGo for real-time information
